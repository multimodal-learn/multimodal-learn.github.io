# Website Design: Small Data, Rich Sensing

**Workshop:** Small Data, Rich Sensing: Multimodal Learning for Robotic Manipulation
**Venue:** IROS 2026
**URL:** http://multimodal-learn.github.io/
**Date:** 2026-02-23

---

## Technology

- Plain HTML + CSS + JavaScript, no build toolchain
- Hosted on GitHub Pages from `index.html` at repo root
- Tailwind CSS via CDN for styling
- Inter font via Google Fonts

---

## Visual Style

- **Background:** White `#ffffff`, with light gray `#f8fafc` alternating sections
- **Accent color:** Navy `#1e3a8a`
- **Font:** Inter (Google Fonts)
- **Nav:** Sticky top bar, white bg, border-bottom on scroll, navy hover underlines
- **Hero:** Centered text, navy title, gray subtitle, two outlined CTA buttons
- **Speaker cards:** Circular photo, bold name, gray affiliation, external link
- **Schedule:** Table with alternating row bg `#f1f5f9`, bold time column
- **Sections:** Alternate white → light gray → white

---
